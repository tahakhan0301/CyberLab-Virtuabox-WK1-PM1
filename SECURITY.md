# Security and Responsible Use

## Scope

This repository documents a personal educational lab. It is not authorization to test any third-party system.

## Safe-use principles

- Test only systems you own or have explicit permission to assess.
- Prefer isolated or host-only networks for experiments that do not require internet access.
- Do not expose vulnerable lab services to public or untrusted networks.
- Avoid using real credentials or personal data in lab exercises.
- Do not commit passwords, access tokens, private keys, VPN profiles, or sensitive configuration files.
- Review screenshots and logs before publishing them.

## Reporting a concern

If you find a secret or sensitive detail in this repository, remove it from the current files and assess whether it was already committed to Git history. Treat exposed credentials as compromised and rotate or revoke them. Deleting a line in a later commit does not erase it from earlier history.

For security concerns, contact the repository owner through their GitHub profile. Do not include sensitive details in a public issue.
