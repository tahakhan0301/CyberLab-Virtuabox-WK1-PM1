# Contributing

Suggestions that improve clarity, reproducibility, and safety are welcome.

## Before proposing a change

- Keep instructions beginner-friendly and technically accurate.
- Include the relevant software version when behavior may vary.
- Distinguish verified results from assumptions.
- Do not add credentials, private data, or identifying screenshots.
- Keep experiments within authorized lab systems.

## Suggested workflow

1. Open an issue describing the proposed improvement.
2. Create a branch for the change.
3. Update the relevant Markdown guide.
4. Verify command syntax and links.
5. Submit a pull request with a concise summary and test notes.
